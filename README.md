# 🕊️ Документация мода Decorative Wings

Данный мод позволяет добавлять в игру кастомные крылья и детально настраивать их визуализацию и поведение через конфигурационные файлы.

---

## ⚙️ Часть 1: Настройка анимаций

Все настройки анимаций хранятся в файле: `config/decorativewings/animations.json`.

### 1.1 Структура конфигурации
Конфигурация представляет собой вложенную карту: **Тип крыльев (style)** $\rightarrow$ **Состояние игрока (state)** $\rightarrow$ **Параметры**.

```json
{
  "название_типа_крыльев": {
    "название_состояния": {
      "beatRate": 0.05,
      "snap": 0.1,
      "spread": 13.0,
      "fold": 14.0,
      "swayBase": 0.0,
      "swayAmp": 0.0,
      "stretch": 1.0,
      "twist": 5.0,
      "pitch": 0.0,
      "bank": 0.0,
      "curl": 4.0,
      "dihedral": 8.0,
      "flutter": 0.8,
      "flapBase": 0.0,
      "flapAmp": 5.0,
      "phaseOffset": 0.0
    }
  }
}
```


### 1.2 Описание параметров
| Параметр | Описание |
| :--- | :--- |
| `beatRate` | Скорость взмахов крыльями. |
| `snap` | Скорость интерполяции между состояниями (чем выше, тем резче переход). |
| `spread` / `fold` | Степень размаха / Степень складывания крыльев. |
| `swayBase` / `swayAmp` | Базовое смещение и амплитуда покачивания. |
| `stretch` | Коэффициент растяжения модели. |
| `twist` | Угол закручивания крыльев. |
| `pitch` / `bank` | Наклон по вертикали (тангаж) / Наклон в стороны (крен). |
| `curl` | Степень изгиба края крыла. |
| `dihedral` | V-образный угол расстановки крыльев. |
| `flutter` | Интенсивность мелкого дрожания/вибрации. |
| `flapBase` / `flapAmp` | Базовая точка и амплитуда взмаха. |
| `phaseOffset` | Смещение фазы для создания асинхронности. |

### 1.3 Поддерживаемые состояния (`States`)
Если состояние не указано в конфиге, используются значения по умолчанию.
*   **Движение:** `walk`, `sprint`, `jump`, `fall`, `crouch`, `climb`.
*   **Полет:** `flying`, `elytra`.
*   **Окружение:** `swimming`, `water`.
*   **Прочее:** `default` (покой), `passenger` (пассажир), `spin` (вращение), `sleeping` (сон).

## 🎨 Часть 2: Создание воксельных крыльев

Воксельные крылья создаются на основе 2D-текстуры, которая затем разворачивается в 3D.

### 2.1 Структура папок
`config/decorativewings/`
*   `/textures/` — PNG изображения.
*   `/wings/` — JSON файлы настроек.

### 2.2 Инструкция по созданию
1.  **Текстура:** Создайте PNG с прозрачным фоном. Рисуйте только **одно** крыло — второе будет зеркальным. Положите в `/textures/`.
2.  **Конфиг:** Создайте JSON в `/wings/` по шаблону:

```json
{
  "id": "my_custom_wings",
  "texture": "my_wings.png",
  "sculpt": true,
  "attachOnRight": true,
  "targetHeight": 15.0,
  "perPixel": false
}
```


**Разбор параметров:**
*   `sculpt`: `true` — объемная модель (ребра толще перепонок), `false` — плоская.
*   `attachOnRight`: сторона прикрепления к игроку.
*   `targetHeight`: высота крыльев в блоках.
*   `perPixel`: `true` — режим "цифровых" крыльев (каждый пиксель $\rightarrow$ куб).

## 🧊 Часть 3: Добавление 3D-крыльев (FBX/Mesh)

Для высокополигональных моделей используется полноценная геометрия.

### 3.1 Структура папок
`config/decorativewings/`
*   `wings_3d/` — JSON-определения.
*   `models/` — файлы геометрии (`.json`).
*   `textures_3d/` — текстурные карты (`.png`).

### 3.2 Инструкция по созданию
1.  **Модель и Текстура:** Экспортируйте модель в JSON и создайте соответствующую PNG-развертку.
2.  **Файл-связка:** Создайте JSON в `wings_3d/`:

```json
{
  "id": "dragon_wings",
  "modelFile": "dragon_wings.json",
  "texture": "dragon_wings_tex.png"
}
```


### 3.3 Технические требования для авторов
*   **Зонирование:** Система делит модель на 3 зоны (`Inner`, `Mid`, `Outer`) по оси X для корректного сгиба.
*   **Ориентация:** Модели должны быть ориентированы по плоскости YZ.
*   **Оптимизация:** Рекомендуется использовать Low-poly сетку для сохранения FPS.

---

## 🚀 Команды и управление

1.  **Применение изменений:** Перезагрузите игру или нажмите **F3 + T**.
2.  **Выдача крыльев:** `/wings give <ник> <id>`
3.  **Снятие крыльев:** `/wings remove <ник>`
4.  **Подсказка:** При вводе команды используйте клавишу **Tab** для выбора доступных ID.
