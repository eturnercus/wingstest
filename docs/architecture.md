# Документация архитектуры Decorative Wings

## Обзор
Мод Decorative Wings реализует гибкую систему добавления кастомных анимированных моделей крыльев для игроков. Для обеспечения удобства поддержки и расширяемости мод использует сервисно-ориентированную архитектуру, которая разделяет загрузку конфигурации, генерацию мешей и рендеринг.

## Основные компоненты

### 1. WingMesh (Слой абстракции)
Для поддержки различных типов крыльев (например, Voxel и FBX) мод использует интерфейс `WingMesh`. Это позволяет системе рендеринга работать со всеми крыльями единообразно, независимо от их внутренней геометрии.
- **`VoxelWingMesh`**: Генерирует 3D-меш из 2D-спрайта.
- **`FbxWingMesh`**: Загружает высокополигональную геометрию из мешей, определенных в JSON.

### 2. Управляемые сервисы
Мод опирается на несколько сервисов (по принципу синглтона) для управления жизненным циклом ресурсов крыльев:

- **`WingConfigManager`**:
  - Загружает `animations.json` и общие настройки мода.
  - Управляет флагом совместимости с «крыльями v1» (legacy flag).
  - Предоставляет унифицированный API для получения параметров анимации для конкретных состояний.
- **`WingMeshProvider`**:
  - Сканирует директории конфигурации на наличие определений крыльев.
  - Создает экземпляры и кэширует реализации `WingMesh`.
  - Предоставляет центральный реестр доступных ID крыльев.
- **`WingResourceLoader`**:
  - Определяет текстуры и модели, проверяя наличие локальных переопределений в конфигах перед переходом к внутренним ресурсам мода.

### 3. Конвейер рендеринга (Rendering Pipeline)
Рендеринг осуществляется через `WingsLayer`, который внедряется в модель рендеринга игрока.
1. **Сэмплирование состояния**: `WingAnimator` вычисляет текущее состояние анимации (взмах, раскрытие и т. д.) на основе движения игрока и его текущей позы.
2. **Получение меша**: `WingsLayer` запрашивает у `WingMeshProvider` меш, соответствующий текущему стилю игрока.
3. **Унифицированный рендеринг**: Слой вызывает метод `WingMesh.render(...)`, делегируя генерацию конкретных вершин реализации меша.

## Поток данных
`Атрибут игрока (Style ID)` $\rightarrow$ `WingMeshProvider (Экземпляр меша)` $\rightarrow$ `WingAnimator (Состояние анимации)` $\rightarrow$ `WingMesh.render()` $\rightarrow$ `VertexConsumer`

## Конфигурация и расширяемость
Добавление нового типа крыльев включает в себя:
1. Реализацию интерфейса `WingMesh`.
2. Добавление логики загрузки в `WingMeshProvider`.
3. Добавление соответствующего JSON-определения в папки конфигурации.
