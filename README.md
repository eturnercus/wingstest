# Документация по настройке анимаций Decorative Wings

Данный мод позволяет детально настраивать поведение и визуализацию крыльев для различных типов и состояний игрока через внешний конфигурационный файл.

## ⚙️ Конфигурация

Все настройки анимаций хранятся в JSON-файле по следующему пути:
`config/decorativewings/animations.json`

### Структура файла
Конфигурация представляет собой карту, где первым ключом является **тип крыльев** (style), а вторым — **состояние игрока** (state).

```json
{
  "название_типа_крыльев": {
    "название_состояния": {
      "beatRate": 0.05,
      "snap": 0.1,
      "spread": 13.0,
      "fold": 14.0,
      "swayBase": 0.0,
      "swayAmp": 0.0,
      "stretch": 1.0,
      "twist": 5.0,
      "pitch": 0.0,
      "bank": 0.0,
      "curl": 4.0,
      "dihedral": 8.0,
      "flutter": 0.8,
      "flapBase": 0.0,
      "flapAmp": 5.0,
      "phaseOffset": 0.0
    }
  }
}
```


## 🛠 Параметры анимации

| Параметр | Описание |
| :--- | :--- |
| `beatRate` | Скорость взмахов крыльями. |
| `snap` | Скорость перехода (интерполяции) между разными состояниями. Чем выше значение, тем резче смена позы. |
| `spread` | Степень размаха крыльев. |
| `fold` | Степень складывания крыльев. |
| `swayBase` | Базовое смещение покачивания. |
| `swayAmp` | Амплитуда покачивания крыльев. |
| `stretch` | Коэффициент растяжения модели. |
| `twist` | Угол закручивания крыльев. |
| `pitch` | Наклон крыльев по вертикали. |
| `bank` | Наклон крыльев в стороны (крен). |
| `curl` | Степень изгиба (завитка) края крыла. |
| `dihedral` | V-образный угол расстановки крыльев. |
| `flutter` | Интенсивность мелкого дрожания/вибрации крыльев. |
| `flapBase` | Базовая точка взмаха. |
| `flapAmp` | Амплитуда взмаха (насколько высоко поднимаются/опускаются крылья). |
| `phaseOffset` | Смещение фазы анимации для создания асинхронности. |

## 🏃 Поддерживаемые состояния (States)

Мод автоматически определяет состояние игрока и применяет соответствующие параметры из конфига. Если состояние не указано в файле, будут использованы значения по умолчанию.

- `default` — стандартное состояние (покой).
- `walk` — при ходьбе.
- `sprint` — при беге.
- `jump` — в момент прыжка (движение вверх).
- `fall` — при падении.
- `flying` — в режиме полета.
- `elytra` — при полете на элитрах.
- `crouch` — при приседании.
- `swimming` — при плавании.
- `water` — нахождение в воде.
- `climb` — при карабканье по лестнице.
- `passenger` — когда игрок является пассажиром (сидит на мобе/транспорте).
- `spin` — при использовании атаки с вращением.
- `sleeping` — во время сна.

## 💡 Особенности поведения

1.  **Типы крыльев**:
    - **Насекомые (Insect)**: Скорость взмахов (`beatRate`) и интенсивность дрожания (`flutter`) автоматически увеличиваются в 2 раза.
    - **Версия V1**: Для моделей первого поколения амплитуда взмахов и покачиваний увеличена, а скорость взмахов повышена в 1.5 раза.
2.  **Динамические эффекты**:
    - **Посадка**: При прекращении полета крылья автоматически сильнее складываются (`fold`) и уменьшают размах (`spread`) для плавного перехода.
    - **Маневрирование**: Наклон крыльев (`bank`) и покачивание (`sway`) зависят от бокового перемещения игрока (strafe).
    - **Полет**: Наклон (`pitch`) в режиме полета динамически меняется в зависимости от вертикальной скорости игрока.

# 🕊️ Руководство по созданию своих крыльев (Custom Wings)

## 📁 Где хранить файлы?
Все пользовательские крылья должны находиться в папке с игрой по следующему пути:
`config/decorativewings/`

Внутри этой папки создайте две подпапки (если их ещё нет):
1.  `/textures/` — сюда кладите ваши изображения `.png`.
2.  `/wings/` — сюда кладите файлы настроек `.json`.

---

## 🛠️ Пошаговая инструкция по созданию

### Шаг 1: Рисуем текстуру
Создайте изображение крыла в формате **PNG** с прозрачным фоном.
*   **Важно:** Рисуйте только **одно** крыло (левое или правое). Мод автоматически создаст зеркальную копию для второй стороны.
*   **Совет:** Чем больше деталей и контрастности в рисунке, тем интереснее будет выглядеть 3D-модель.
*   Поместите файл в `config/decorativewings/textures/` (например, `my_wings.png`).

### Шаг 2: Создаем файл настроек
В папке `config/decorativewings/wings/` создайте текстовый файл с расширением `.json` (например, `my_wings.json`).

Скопируйте в него следующий шаблон и настройте под себя:

```json
{
  "id": "my_custom_wings",
  "textureFile": "my_wings.png",
  "sculpt": true,
  "attachOnRight": true,
  "targetHeight": 15.0,
  "perPixel": false
}
```


### ⚙️ Разбор настроек JSON:
*   **`id`**: Уникальное имя ваших крыльев. Именно это слово вы будете писать в команде `/wings give`. (Например: `"demon_wings"`).
*   **`textureFile`**: Точное имя файла картинки, который вы положили в папку `/textures/`.
*   **`sculpt`**:
    *   `true` — **Скульптурный режим**. Мод создает объемную модель с разной толщиной (ребра крыльев будут толще, перепонки — тоньше). Рекомендуется для органических крыльев.
    *   `false` — Модель будет плоской или пиксельной.
*   **`attachOnRight`**:
    *   `true` — Крыло крепится к игроку правым краем картинки.
    *   `false` — Крыло крепится левым краем.
*   **`targetHeight`**: Желаемая высота крыльев в блоках (например, `15.0` или `20.0`).
*   **`perPixel`**:
    *   `true` — **Пиксельный режим**. Каждая точка картинки станет отдельным маленьким кубиком. Идеально для "цифровых" или магических крыльев.
    *   `false` — Обычный режим (с использованием `sculpt`).

## 🚀 Как применить в игре?

1.  Запустите игру (или, если она уже запущена, нажмите **F3 + T**, чтобы обновить ресурсы).
2.  Используйте команду:
    ` /wings give <ник_игрока> <id_из_json> `
    *Пример:* `/wings give Player1 my_custom_wings`

### 💡 Полезные советы:
*   **Быстрый подбор:** При вводе команды `/wings give <игрок> ` нажмите **Tab**, и игра предложит вам список всех доступных ID из ваших JSON-файлов.
*   **Эксперименты:** Вы можете менять значения в `.json` файле (например, менять высоту или переключать `sculpt`), после чего просто нажать **F3 + T** в игре, чтобы мгновенно увидеть изменения!
*   **Удаление:** Чтобы снять крылья, используйте команду `/wings remove <ник_игрока>`.
