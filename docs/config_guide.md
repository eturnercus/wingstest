# Руководство по конфигурации: Decorative Wings

В данном руководстве объясняется, как добавлять собственные крылья и настраивать их анимации.

## Структура директорий
Все конфигурации находятся в `config/decorativewings/`.

```plain text
config/decorativewings/
├── animations.json      # Глобальные параметры анимации
├── settings.json       # Настройки мода (например, флаг крыльев v1)
├── textures/           # Переопределения текстур (.png)
├── wings/              # Определения воксельных крыльев (.json)
├── wings_3d/           # Определения 3D крыльев (.json)
└── models/             # Файлы 3D моделей (.json)
```


## Создание воксельных крыльев
Воксельные крылья создаются из 2D-спрайта, который затем выдавливается в 3D.

1. **Текстура**: Создайте PNG-файл одного крыла. Поместите его в `/textures/`.
2. **Определение**: Создайте JSON-файл в `/wings/`:
```json
{
  "id": "my_wings",
  "texture": "my_wings.png",
  "sculpt": true,
  "attachOnRight": true,
  "targetHeight": 15.0,
  "perPixel": false
}
```


## Создание 3D (FBX) крыльев
3D крылья используют высокополигональную геометрию.

1. **Модель и текстура**: Поместите JSON-файл модели в `/models/`, а PNG-текстуру в `/textures/`.
2. **Определение**: Создайте JSON-файл в `/wings_3d/`:
```json
{
  "id": "dragon_wings",
  "modelFile": "dragon_wings.json",
  "texture": "dragon_wings_tex.png"
}
```


## Настройка анимаций
Анимации определяются в `animations.json` по формату: `ID стиля` $\rightarrow$ `Состояние` $\rightarrow$ `Параметры`.

### Общие параметры
- `beatRate`: Скорость взмаха крыльев.
- `snap`: Скорость перехода между состояниями.
- `spread` / `fold`: Диапазон раскрытия/складывания крыльев.
- `swayAmp`: Интенсивность покачивания в режиме покоя.
- `flutter`: Скорость высокочастотной вибрации (трепетания).

### Поддерживаемые состояния
- `default`: Состояние покоя.
- `walk` / `sprint`: Передвижение по земле.
- `flying` / `elytra`: Передвижение по воздуху.
- `jump` / `fall`: Вертикальное перемещение (прыжок/падение).
- `swimming` / `water`: Передвижение в воде.
- `sleeping`: Поза во время сна.

## Крылья v1
Включите флаг `v1WingsEnabled` в `settings.json`.
